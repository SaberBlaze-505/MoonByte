# Hardware Documentation

The `pcb/gerber/` directory contains selected Gerber manufacturing outputs from the project, including copper, mask, paste, silkscreen, and board-edge layers.

These are generated fabrication outputs, not an editable KiCad PCB source project. The complete schematic, assembly drawing, and full drill/fabrication package are not included in this upload. Review the board dimensions, required fabrication layers, electrical rules, and safety requirements before ordering or assembling a board. Hardware connected to mains voltage requires appropriate electrical safety procedures and supervision.
